## 教材がこの手本に加えた編集


底本は、公式リファレンスの Literals（Array / Hash / Range Literals 節）と Enumerable の
各メソッドの項、および Array / Hash の項。加えた編集は次のとおり。

1. **`# => ` のコメントを `assert_equal` に置き換えた。** Enumerable の項は
   `(0..4).map {|i| i*i } # => [0, 1, 4, 9, 16]` の形で例を挙げている。値はそのまま使った。
2. **空白を教材の RuboCop 設定に合わせた。** 原典は `{|i| i*i }` のように `{` の直後と
   演算子の周りの空白を詰めて書いている。この書き方は教材の書式検査（Layout 部門）に当たるので、
   `{ |i| i * i }` に開いた。中身は変えていない。
3. **`each` がレシーバを返すことを確かめる 4 行は教材が書いた。** Array#each の項に
   「戻り値は self」と書かれている性質を、JS の `forEach` との対比のために明示した。
4. **`inject` の例は 2 つとも原典のもの。** 初期値を渡す形（`[2, 3, 4].inject(1) do … end`）と、
   省く形を並べた。省くと先頭の要素が初期値になる。
