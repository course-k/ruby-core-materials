# 模範解説（検体）

この課題は `bin/check` の動作確認用の検体であり、学習者向けの教材ではない。
模範解説の位置と分量の見本として最小限だけ置く。

- `%w[ada grace linus]` は文字列の配列リテラル。引用符とカンマを書かずに済む。
- `map(&:upcase)` の `&:upcase` は Symbol を Proc に変換して渡す書き方。
- `reduce(0) { |sum, n| ... }` の第 1 引数は初期値。省略すると先頭要素が初期値になる。
- `assert_nil [].first` — 空配列の `first` は `nil` を返す。例外にはならない。
