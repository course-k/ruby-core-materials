# ruby-core-materials — Ruby 軸の教材リポジトリ

Ruby / Ruby on Rails の学習計画（`~/lab/ruby-learning/docs/`）のうち、**Ruby 軸の教材**を置くリポジトリ。
課題文・手本の原本・確認課題の雛形とテスト・封緘物・模範解説・判定ツール `bin/check` が入る。

学習者の解答は別のリポジトリ（成果リポ `ruby-core`）に入る。このリポジトリは学習者にとって
**読み取り専用**で、ここへコミットしない。

## AI 生成の教材であることの開示

**このリポジトリの中身は AI が生成した教材である。** 課題文・仕様・テスト・雛形・模範解説・判定ツールの
すべてが AI の生成物で、コミットは Co-Authored-By で識別できる形にしている。

学習者は**課題の解答に AI を使わない**。コードと「なぜこう書くか」の記述は学習者本人が書く。
AI が関与するのは教材の設計・生成・検品・判定の側だけであり、学習者の解答には関与しない。
この構図に AI の外の基準を 3 つ入れている——①書き写す手本は AI 生成物ではなく実在の一次資料
（公式ドキュメント・公式ガイド・Ruby 製著名ツールの公式リポジトリ）から取る、②レベル出口の課題は
盲検で運用する、③公開（RubyGems 公開・デプロイ）を応用の完了条件に置き、判定の終点を教材の外に出す。

## 使い方

道具を入れる（Ruby 4.0.6 は mise で導入する）。

```sh
mise use -g ruby@4.0
bundle config set --local path vendor/bundle
bundle install
```

課題を進める。`<成果リポ>` は学習者のリポジトリ（`ruby-core`）のパス。

```sh
bin/check --start <課題番号> <成果リポのパス>    # 着手する
bin/check         <課題番号> <成果リポのパス>    # 判定する
bin/check --report <課題番号> <成果リポのパス>   # 判定ログだけを書き出す
```

### `bin/check` が何をするか

| 呼び出し | すること |
|---|---|
| `bin/check <課題番号> <成果リポ>` | その課題の判定項目をすべて走らせ、合格 / 失敗 / 未着手を表示する |
| `--start` | 着手を記録し、着手後に開く封緘物を復号して復号先のパスを表示する。判定はしない |
| `--report` | 判定ログを `<成果リポ>/.check/<課題番号>-report.md` へ書き出し、パスだけを表示する |

- まだ手を付けていない項目は「失敗」ではなく「未着手」と出る。写しだけを終えた段階で走らせると、
  写しの 3 項目（実行・アサーション数・書式）の結果だけが合否として出る。
- 判定の記録は成果リポの `.check/<課題番号>.yml` に残る（機械の記録。学習者が書く `progress.md` とは
  役割が別）。
- 判定に使うテストは一時ディレクトリで実行して残さない。失敗したときに見えるのはテスト名と
  失敗メッセージの 1 行目だけ。
- 学習者コードのテストは**成果リポの Gemfile**で、RuboCop は**教材リポの Gemfile**で実行する。

**終了コード**: `0` 合格（または未着手のみ） / `1` 判定失敗 / `2` 使い方エラー（課題番号の誤り・
成果リポ不在・鍵不在・道具不在）。

### 封緘物

課題によっては、仕様本文や判定テストが暗号化された状態でこのリポジトリに入っている（`sealed/`）。
学習者が着手前に中身を見ないためで、`bin/check` 以外の経路で開かないことを規約として運用する。

鍵はどちらのリポジトリの外にも置く。既定は `~/.config/ruby-learning/seal.key` で、環境変数
`RUBY_LEARNING_SEAL_KEY_FILE` で場所を変えられる。鍵が無いときは終了コード 2 で止まる。
復号先はこのリポジトリの `unsealed/<課題番号>/`（`.gitignore` 済み）。

## リポジトリ構成

```
README.md              本書
Gemfile                教材側の道具（minitest・rubocop。版は固定）
.ruby-version          4.0.6
.rubocop.yml           書き写し用の RuboCop 設定（根幹文書 §3.1 を写したもの）
bin/check              共通の判定ツール
bin/seal               封緘物を暗号化するコマンド（課題を作る人が使う）
docs/
  check-yml.md         tasks/<課題番号>/check.yml のスキーマ
  materials-guide.md   課題を作る人向けの手引き
  selfcheck-log.md     bin/check の実機実行ログ
tasks/
  rb1-00-selfcheck/    bin/check の検体（下記）
  rb1-NN-<slug>/       Ruby 基礎の課題（rb1 は Ruby 基礎）
unsealed/              封緘物の復号先（gitignore 済み）
```

**`tasks/rb1-00-selfcheck/` は学習者向けの課題ではない。** `bin/check` の判定項目 8 種すべてを
1 つのディレクトリで動かすための**基盤の検体**であり、学習の課題一覧（設計文書「Ruby 基礎」§3）には
含まれない。学習者はこれを解かない。実機で走らせた記録は `docs/selfcheck-log.md`。
